A private universe
for two

A cinematic memory archive for exactly two people: photos, a timeline, and letters that stay sealed until a chosen day. Self-hosted on your own Supabase and Vercel.

View on GitHub Quick start

What's inside

Live counter

Time together, in calendar years, months and days, computed in your timezone.

Memories

Multi-photo upload, private storage, signed URLs, year and category filters.

Timeline

Events in order of time, each with an optional photo.

Time-locked letters

The lock is enforced by the database (RLS and functions), not by the UI.

Two-user allowlist

No public sign-up. A trigger caps the allowlist at two people.

Safe by default

RLS on every table, no service_role in the app, safe redirects.

Quick start

  1. Create a Supabase project and run supabase/migrations/*.sql in order.
  2. Disable public sign-up (Auth → Providers → Email) and create two users.
  3. Allowlist them with supabase/add_allowed_users.sql.
  4. Personalize names and dates in lib/site-config.ts.
  5. Run locally, then deploy to Vercel with the same env vars.
git clone https://github.com/gregreshetnyak52-crypto/Our-Private-Universe
cd Our-Private-Universe
cp .env.example .env.local
npm install && npm run dev

Good to know

This page is only a project description. The app itself needs a server and a database, so it cannot run on GitHub Pages — deploy it to Vercel or any Node host. The interface language is Russian; texts live in the components and lib/site-config.ts.
